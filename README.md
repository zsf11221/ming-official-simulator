刻意改掉的短板：
1. 节奏太慢：旧版 1x 每 12 秒一日，走完 1378–1402 约 24 年要约 29 小时，前 4 个月只出 1 个事件，挂机感强。本版按年推进，每年固定 3 个抉择，事件密度高得多，不用实时等待。
2. 桌面三栏宽屏不适合直接搬：本版竖屏触屏、大按钮、单列布局，390px 优先。
3. 失败/结局规则不透明：本版界面写清三条风险线（政绩<20 贬谪 · 贪墨≥80 弹劾罢官 · 健康≤0 病逝 / 民心≤0 民变罢官）和考课规则。
4. 旧版要两次优秀才升知州：微信版为节奏改为一次优秀即升，考课仍三年一次。
5. 旧版无微信分享入口：本版海报可下载，小游戏版用 `wx.shareAppMessage`。

## 玩法

- **开局**：洪武十一年（1378年）1月1日，正七品清河县知县。出身三选一 + 天赋三选一，主角虚构，可改名。初始县情：300户、1000人、耕地 370 亩、残破县城。六维：治理/学识/财计/统御/德行/体魄。
- **资源（公私分账）**：官库银两（公产）、俸余（个人钱）、官仓粮食、耕地、户数、人口、民心、治安、吏治、声望、政绩、健康、贪墨风险、朝廷信任；属性：才学、人脉、六维；材料：功绩。
- **核心循环（可长玩、可读档）**：按年推进，每年做 3 个抉择（断案、劝农、兴学、修水利、赈灾、结亲育子、拜访上官、应对考课等，事件库 54 条）。三年一考课，政绩够就升官：知县 → 知州 → 知府 → 布政使 → 六部侍郎 → 六部尚书 → 内阁首辅；政绩太差就贬谪；民心 / 健康归零就结局。
- **读档**：自动保存 + 手动存档 3 个槽，关掉再开能继续。网页版用 `localStorage`，小游戏版用 `wx.setStorageSync / wx.getStorageSync`，同一份存档结构。首页有“继续游戏 / 新开一局 / 读档”。
- **升级打装备**：正常玩掉功绩升级装备：官服、官印、靠山、门生、良田、护身符（各 5 级）。卡住时看广告加速：小游戏接 `wx.createRewardedVideoAd` 占位（无广告单元 ID 时降级不报错），网页版用 3 秒模拟广告倒计时领奖励。免费路永远能通关，广告只是加速，绝不做付费买装备。
- **家族传承（轻量）**：主角老了 / 致仕 / 出事后，成年子嗣可继承 50% 声望、人脉和 30% 家产，从低两级官职重新开始，多代可玩。
- **分享**：每升官一次、每出一个结局，都生成 Canvas 海报（官职、年份、政绩、民心、一句评语）。网页版可下载图片，小游戏版用 `wx.shareAppMessage` / 保存图片。

## 历史说明（游戏化简化）

- 洪武元年 1368 年建明，洪武十一年为 1378 年。
- 洪武十三年（1380 年）废丞相、设六部，此后无丞相；“内阁首辅”为后期叫法，本游戏作顶级目标使用，已在代码注释中注明。
- 胡惟庸案、空印案、郭桓案、蓝玉案只作背景风声，不渲染血腥、暴力、自杀等细节。

## 合规

个人主体，纯广告变现（IAA），不做内购 / 虚拟支付（要企业主体 + 版号）。不做算命 / 抽签 / 运势，不做赌博抽卡付费。广告占比 ≤50%，不遮挡核心功能，不诱导分享 / 关注。

## 微信小游戏接入

1. 在微信公众平台注册小游戏账号，类目选“游戏”，子类目先选“休闲游戏”，拿到 AppID。
2. 把 AppID 填进 `project.config.json` 的 `appid`。
3. 用微信开发者工具导入本仓库，选“小游戏”，即可真机预览。
4. 激励视频：把广告单元 ID 填进 `game.js` 的 `watchAd()`（`adUnitId: ''` 处）。
5. 发布前需过版本审核 + 备案；个人主体走 IAA 纯广告，预计 13–37 个工作日。
